# 视频号拦截器

一个帮助您控制微信视频号使用的Android应用。当您打开微信视频号时,应用会要求您进行反思,帮助您更有意识地使用短视频。

## 功能特点

- 📱 **智能检测**: 自动检测微信视频号页面(类名+文本双重检测)
- ✍️ **强制反思**: 弹出拦截界面,要求输入至少50个字符的反思
- ⏰ **冷却机制**: 提交后有冷却期(默认10分钟)
- 🎯 **灵活配置**: 可自定义最小字符数、冷却时间、提示语和检测关键词
- 📚 **历史记录**: 保存所有反思记录
- 🔧 **调试工具**: 帮助适配不同微信版本

## 快速开始

### 安装

1. 下载[最新APK](https://github.com/baiyx321/wechatvideo/releases)
2. 在手机上安装(需允许安装未知来源)
3. 打开应用,点击"启用服务"
4. 在无障碍设置中启用"视频号拦截器"
5. 返回应用确认服务已启用(绿色)

### ROM保活设置

为确保后台正常工作:

**小米/红米**: 设置→应用管理→视频号拦截器→自启动(开)、省电策略(无限制)  
**华为**: 设置→应用启动管理→手动管理(全开)  
**OPPO**: 设置→应用权限→自启动(开)、关联启动(开)  
**vivo**: 设置→权限管理→自启动(开)  
**通用**: 最近任务中锁定应用

## 使用说明

1. 启用服务后,应用在后台监控微信
2. 打开视频号时,弹出拦截界面
3. 输入至少50字的反思(可在设置中调整)
4. 提交后进入10分钟冷却期(可调整)
5. 在"历史记录"查看所有反思
6. 使用"调试校准"适配新版微信

### 如果检测失败

1. 打开"调试校准"界面
2. 打开微信视频号
3. 回到调试界面,查看显示的类名和文本
4. 将有用的关键词复制到"设置"中
5. 保存并重新测试

```
└── ui/                      # UI层
    ├── MainActivity.kt

    ├── DebugActivity.kt
    └── BlockingOverlay.kt      # 拦截覆盖层
```

### 核心技术

- **AccessibilityService**: 监控微信应用
- **双重检测**: 类名匹配 + 文本匹配(至少2个关键词)
- **TYPE_ACCESSIBILITY_OVERLAY**: 全屏覆盖层
- **本地存储**: SharedPreferences(配置) + JSON(历史)
- **分层设计**: 业务逻辑与Android API分离,便于测试

### 检测流程

```
打开微信视频号
  ↓
AccessibilityService检测到窗口变化
  ↓
收集: 包名、类名、可见文本
  ↓
检查: 是否启用? 是否目标应用? 是否冷却中?
  ↓
检测视频号页面:
  - 方法1: 类名包含"finder"等关键词
  - 方法2: 至少2个文本关键词匹配
  ↓
显示拦截覆盖层
  ↓
用户输入反思(实时字符计数)
  ↓
字符数≥最小值时启用提交按钮
  ↓
提交后保存到历史,设置冷却时间
```

## 隐私与安全

- ✅ **无网络权限** - 不上传任何数据
- ✅ **本地存储** - 所有记录保存在设备上
- ✅ **最小权限** - 仅使用无障碍服务
- ✅ **开源透明** - 所有代码可审查

无障碍服务仅用于:
- 检测当前应用和窗口类名
- 读取界面文本(仅用于检测视频号特征)
- 显示覆盖层

不会读取聊天内容或其他敏感信息。

## 已知限制

1. **微信版本**: 微信更新可能改变类名,需使用调试工具更新关键词
2. **系统限制**: Android 10+后台限制,需正确配置保活
3. **应用商店**: Google Play可能拒绝无障碍应用,建议通过GitHub发布
4. **仅限Android**: iOS无法实现类似功能

## 常见问题

**Q: 拦截不生效?**  
A: 检查无障碍服务是否启用、应用是否被清理、是否在冷却期内。如微信更新,使用调试工具更新关键词。

**Q: 如何关闭拦截?**  
A: 在设置中关闭"启用拦截"开关,或在系统设置中关闭无障碍服务。

**Q: 数据会同步到云端吗?**  
A: 不会,所有数据仅保存在本地,应用无网络权限。

**Q: 可以用于其他应用吗?**  
A: 可以,在设置中修改"目标应用包名"和检测关键词即可。
