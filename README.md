# 视频号拦截器

一个帮助您控制微信视频号使用的Android应用。当您打开微信视频号时,应用会要求您进行反思,思考"我为什么要刷视频"和"我现在本该做什么",帮助您更有意识地使用短视频。

## 功能特点

- 📱 **智能检测**: 自动检测微信视频号页面(基于Activity类名和界面文本)
- ✍️ **强制反思**: 弹出拦截界面,要求输入至少50个字符的反思文本
- ⏰ **冷却机制**: 提交反思后有冷却期(默认10分钟),避免过度打扰
- 🎯 **灵活配置**: 可自定义最小字符数、冷却时间、提示语和检测关键词
- 📚 **历史记录**: 保存所有反思记录,方便回顾
- 🔧 **调试工具**: 提供调试校准界面,帮助适配不同微信版本

## 使用说明

### 基本流程

1. 启用无障碍服务后,应用会在后台监控微信的使用
2. 当您打开微信视频号时,会自动弹出拦截界面
3. 需要输入至少50个字符的反思(可自定义数量)
4. 点击"提交"后,内容会保存到历史记录,并进入冷却期
5. 冷却期内(默认10分钟)不会再次拦截

### 设置选项

在"设置"页面可以调整:

- **启用拦截**: 总开关,可临时关闭拦截功能
- **最小字符数**: 提交前需要输入的最少字符数(默认50)
- **冷却时间**: 通过后多久内不再拦截(默认10分钟)
- **提示语设置**: 自定义拦截时显示的问题,可以输入多个提示语用`---`分隔
- **类名关键词**: 用于检测视频号的Activity类名(默认: finder,FinderHomeUI,FinderUI)
- **文本关键词**: 用于检测视频号的界面文本(默认: 视频号,关注,朋友,推荐)
- **目标应用包名**: 要监控的应用包名(默认: com.tencent.mm,可添加测试包名)

### 调试校准

如果应用无法检测到视频号(微信版本更新导致),请使用"调试校准"功能:

1. 打开调试校准界面
2. 打开微信视频号
3. 回到调试界面,查看显示的"当前窗口类名"和"可见文本"
4. 将有用的类名关键词和文本关键词复制到设置中
5. 保存设置后重新测试

### 查看历史记录

在"历史记录"页面可以:
- 查看所有提交的反思记录
- 每条记录显示完整内容和提交时间
- 可以删除单条记录或清空全部记录

## 已知限制

### 技术限制

1. **仅限Android系统**: 本应用使用Android的AccessibilityService,iOS无法实现类似功能
2. **微信版本兼容性**: 微信更新可能改变Activity类名,导致检测失败,需要通过调试校准更新关键词
3. **系统限制**: Android 10+对后台应用限制较严,需要正确配置保活设置
4. **无障碍权限**: 部分系统会定期重置无障碍权限,需要重新授权

### 应用商店政策

- **Google Play**: 对无障碍服务应用审核严格,可能无法上架
- **国内应用商店**: 各家政策不同,部分商店可能拒绝此类应用
- **建议**: 通过GitHub Releases或其他渠道分发APK

### 隐私说明

- 本应用**不会上传**任何数据到互联网
- 反思记录仅保存在本地设备
- 无障碍服务仅用于检测微信视频号界面,不会读取或记录其他内容
- 应用不需要网络权限

## 常见问题

### Q: 为什么拦截不生效?

A: 请检查:
1. 无障碍服务是否已启用
2. 应用是否被系统清理(查看保活设置)
3. 设置中"启用拦截"开关是否打开
4. 是否在冷却期内
5. 微信版本是否更新导致检测失败(使用调试校准工具)

### Q: 如何完全关闭拦截?

A: 有三种方式:
1. 在应用设置中关闭"启用拦截"开关(推荐)
2. 在系统设置中关闭无障碍服务
3. 卸载应用

### Q: 反思记录会同步到云端吗?

A: 不会。所有数据仅保存在本地设备,应用没有网络权限。

### Q: 可以用于其他应用吗?

A: 可以。在设置中修改"目标应用包名"即可监控其他应用,但检测关键词需要针对目标应用调整。

### Q: 为什么需要无障碍权限?

A: 无障碍服务是Android系统提供的合法API,用于:
- 检测当前显示的应用和界面
- 读取界面上的文本内容(仅用于检测视频号特征)
- 显示全局覆盖层(拦截界面)

本应用不会滥用此权限读取敏感信息。
